# ORA — The Self-Sustaining Floating Haven

An immersive cinematic architectural experience imagined and visualized by **Mohannad Haikal**.

ORA explores a floating home where architecture, water, cultivation, and natural rhythms form one living system.

## Live experience

https://ora-floating-haven.mohannad-98.chatgpt.site

## Experience

- Cinematic video prologue
- Nine guided architectural chapters
- Scroll-triggered typography and spatial transitions
- Full-screen image viewer with keyboard navigation
- Responsive desktop and mobile presentation
- Integrated ORA film
- Search and structured metadata

## Development

```bash
pnpm install
pnpm dev
```

Create a production build with:

```bash
pnpm build
```

Large cinematic media is stored in portable repository chunks and is
reassembled automatically before development and production builds.
